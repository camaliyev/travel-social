# 🌍 Travel Social

Travel Social is a full-stack social media web application built with Python and Flask.

The application allows users to create accounts, build profiles, share travel experiences with photos, and interact with other travel posts through likes and comments.

## ✨ Features

- User registration and login
- Secure user authentication
- User profiles
- Profile photo uploads
- Create travel posts
- Upload photos to travel posts
- Add country and city information
- View individual travel posts
- Edit your own posts
- Delete your own posts
- Like travel posts
- Comment on posts
- View post authors and their profiles

## 🛠 Tech Stack

### Backend
- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- Flask-WTF
- WTForms

### Frontend
- HTML
- CSS
- Jinja2

### Database
- SQLite
- SQLAlchemy
- Flask-Migrate / Alembic

### Deployment
- Render
- Gunicorn
- Git / GitHub
